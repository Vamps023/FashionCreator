# Open Source Inventory & Licensing

This document tracks all external open-source libraries, packages, and references utilized within the 3D Fashion Studio platform.

| Package / Reference | Version | License | Source URL | Purpose |
|---|---|---|---|---|
| **Three.js** | ^0.174.0 | MIT | https://github.com/mrdoob/three.js | Core WebGL 3D rendering engine, PBR materials, lights, cameras, and GLTFExporter |
| **Lucide React** | ^1.16.0 | MIT | https://github.com/lucide-icons/lucide | Studio icons and visual navigation components |
| **Zustand** | ^5.0.3 | MIT | https://github.com/pmndrs/zustand | Lightweight, predictable reactive state management for the garment document model |
| **Canvas API / React-Konva** | - | MIT | https://github.com/konvajs/react-konva | 2D artwork canvas compositing, text, vector layers, and texture baking |
| **GarmentCode (Research Ref)** | MIT | Reference | https://github.com/maria-korosteleva/GarmentCode | Research reference for sewing pattern geometry and parametric sizing specifications |
| **glTF Transform (Pipeline Ref)** | MIT | Reference | https://github.com/donmccurdy/glTF-Transform | 3D model optimization, Draco/Meshopt compression, and KTX2 texture workflows |

*Policy: Experimental research code is strictly segregated in adaptation layers and evaluated for license compliance prior to production deployment.*
